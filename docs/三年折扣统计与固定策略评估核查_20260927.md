# 三年折扣统计与固定策略评估核查

日期：2026-09-27。实验：`test_full_episode_36/seed-00001-2026-09-27-15-30-56`。
本报告固定使用已完成的第 1—28 轮，每轮 2023-01-01 至 2025-12-31，共 1096 天。
本次未修改训练代码、参数、AGENTS.md 或正在运行的进程。

## 1. 折扣统计实现

严谨修订版第 17 节规定：`J = sum(gamma^t * v) / sum(gamma^t * chi)`。
`harl/common/buffers/constraint_buffer.py` 的 `compute_discounted_active_statistics` 使用批次内 t=0..1095，分子不重复乘 chi。
Runner 在 Actor 更新之后读取统计量，LagrangianManager 用它与 budget 比较并更新乘子。
没有逐年重置折扣，也没有使用全训练累计步数作为指数。

独立复算 28 轮 × 5 项约束，共 140 组统计：

- 日志 mean_cost 与独立复算的最大绝对误差：2.679579023945333e-10。
- 当前 z=1、tolerance=0；日志 v 与 chi*max(0,xi/z-tolerance) 的最大误差为 0。
- 所有已记录 lambda 均为 0。
- `python -m examples.test_cascade_constraint_pipeline`：4 项测试通过，覆盖成本转换、折扣统计及未激活样本等。

**判断：实现符合修订版公式，未发现此处统计计算错误。仅核对修订版，不声称独立核验专利原文。**

## 2. 是否符合三年研究目标

gamma=0.99 且约束全年生效时，2023、2024、2025 在该统计中的权重分别为 97.4498%、2.4874%、0.0628%。同一年内部，较晚日期也被降低权重。
该统计描述从周期起点开始的折扣约束，不等于三年日期等权约束，也不等于逐日零违规。

第 28 轮三峡：

| 指标 | 结果 |
|---|---:|
| 用于 lambda 更新的折扣均值 | 0.00380305 |
| 三年等权平均 cost | 0.03199727 |
| 配置预算 | 0.02 |
| 2023 年等权平均 cost | 0.027557 |
| 2024 年等权平均 cost | 0.041209 |
| 2025 年等权平均 cost | 0.027201 |
| 三年生态违反天数 | 58 |

三峡在全部 28 轮中的三年等权均值都大于 0.02，但这不等于违反当前正式的“折扣预算”定义。cost 是平方根缺额变换后的无量纲量，不可直接解释为缺水百分比。

结论分两层：

1. 以修订版明确的折扣预算为标准，计算一致。
2. 若研究希望整个三年均衡满足长期任务，目前指标不足以证明目标实现，且已经观察到折扣通过、等权均值高于 0.02 同时存在。

文档未明确要求三年等权或逐年单独达标，不应未经确认把 gamma 改成 1、取消折扣、降低预算或强行提高 lambda。
建议正式评估并列报告折扣、全周期及逐年有效样本均值、违反天数、原始生态缺额和末期库容。如果改变训练目标，须先明确目标，再同步文档、统计实现、预算解释和测试。

## 3. 已有完整周期轨迹比较

Runner 在整轮 rollout 完成之后才 compute/train，因此每个 1096 天周期内 Actor 参数固定。
第 1 轮是未更新策略的一次随机采样轨迹；第 28 轮是已完成 27 次更新的策略的一次随机采样轨迹。
两者使用同一来水与 reset 初始状态；并非持出年份评估，也不是多次重复评估。

| 指标 | 初始策略：第 1 轮 | 第 28 轮采集策略 |
|---|---:|---:|
| 三年总发电量（TWh） | 938.609882 | 941.344084 |
| 累计 reward | 577.677180 | 579.359973 |
| 三峡生态违反天数 | 44 | 58 |
| 三峡等权平均 cost | 0.025850 | 0.031997 |
| 三峡折扣平均 cost | 0.003512 | 0.003803 |
| 最终 fallback 天数 | 1 | 0 |

发电量单轨迹差异为 +0.2913%，三峡生态指标变差，不能据此认定多目标性能提升。各库末期储水不同，也需纳入解释；不能凭空添加终端库容约束或把差异全部归因于策略效率。

## 4. 独立固定策略评估的阻塞项
