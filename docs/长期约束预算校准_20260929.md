# 长期约束预算（budget d_j）逐库校准（2026-09-29）

## 范围与研究口径

本记录只校准五条生态长期约束的折扣预算 `d_j`，不改动算法语义、物理参数、安全层、
reward 定义、lambda 学习率或 cost 归一化。

代码核对结论：`budget` 只出现在 `ConstraintCostEvaluator.from_config` 与
`LagrangianManager`，在 `lambda <- max(0, lambda + eta_lambda * (Jhat - d))` 中作为比较阈值使用。
它不进入 Layer-1 的 S201/S202/S203/S3，不进入 mask、观测、物理转移和 reward。
所以调整预算只改变 lambda 是否会增长、以及增长到哪个水平后停止，不改变任何一天的安全动作集合。

用户本轮目标：让约束项真正被激活，预算落在"当前确实违反、但有希望压下去"的区间内，
并允许五库取不同数值。

数据来源：

- 预算敏感性运行（lambda 恒为 0，22 轮完整 1096 天）：
  `results/cascade_reservoir/WDD-BHT-XLD-XJB-THR/happo/mask_accuracy_200_budget001/seed-00001-2026-09-29-18-35-06`。
- 长期约束运行（budget 0.0001，lambda 已增长，149 轮完整 1096 天）：
  `results/cascade_reservoir/WDD-BHT-XLD-XJB-THR/happo/mask_accuracy_200/seed-00001-2026-09-28-20-59-35`。
- 独立可行性审计（不调用生产求解器）：
  `results/feasibility_audit_update140/summary.json`、`results/feasibility_audit_update149b/summary.json`。
- 固定策略完整周期评估（确定性 argmax，同历史区间）：
  评估结果保存在 `results/frozen_comparison_20260928/`；已删除的历史说明文档不再作为当前依据。
- 折扣口径：gamma = 0.99，1096 日批次，第一年权重 97.4498%。

上述数据都来自同一 seed=1、同一来水序列、同一物理与安全配置，因此可直接比较。

## 判定规则

对每个水库取两个实测锚点：

- **U（当前水平）**：预算敏感性运行中 lambda 恒为 0 时的折扣 cost 均值，即当前策略实际达到的水平。
- **L（已展示可达下限）**：长期约束运行 149 轮中该库已真实达到过的最小折扣 cost，
  即至少有一条真实轨迹做到过。

选值规则：`L <= d < U`，并落在区间下半区。这样同时满足两个条件：

1. `d < U`，当前确实违反，gap > 0，lambda 会真正开始增长（约束项被激活）；
2. `d` 不低于已有轨迹展示过的水平，目标不是凭空的不可达数值。

未使用任何没有测量的工程数值。

## 预期动态

初始 gap = U - d_j：WDD 0、BHT +0.00027、XLD +0.00146、XJB +0.00119、THR +0.00303。
按 eta_lambda = 0.05，lambda 每轮增量约 1.4e-5（BHT）、7.3e-5（XLD）、6.0e-5（XJB）、1.5e-4（THR）。
200 轮量级为 0.003 ~ 0.03，与长期约束运行结束时观测到的 lambda
（BHT 0.0016、XLD 0.024、XJB 0.038、THR 0.024，对应 d=0.0001）同一量级。

与 budget=0.0001 的关键差别：那次的 gap 约 0.002 ~ 0.007 且始终无法关闭，
lambda 只能一直线性增长（149 轮后仍在涨）；本次目标位于已展示过的可达区间，
cost 下降后 gap 会收敛，lambda 存在平衡点。

与 budget=0.01 的关键差别：那次五库 gap 全为负，`sum_lambda_A_C_rms=0`、
`penalty/reward=0`、`sign_flip_fraction=0`，约束项对 Actor 完全无效；本次会恢复非零约束项。

## 边界与未决项

- **约束项仍然偏弱**：长期约束运行在 lambda 约 0.02 ~ 0.04 时，
  `penalty/reward` 优势 RMS 比只有 0.0063（约 0.6%），`sign_flip_fraction` 最大 0.0082。
  本次校准只让约束项从 0 变为非零，量级仍是同一数量级。
  若要让约束项主导 Actor，需要另行校准 `lambda_lr`（当前 0.05）或每条约束的
  `normalizer z_j`（当前 1.0）；两者都需要依据，本次未改动。
- **可达性未证明**：L 只说明"某一条真实轨迹达到过"，不构成全局下界；
  也不能据此宣布这些预算一定可以在 200 轮内达成。
- **口径提醒**：budget 比较的是折扣 cost（第一年权重 97.4%）。
  同一批样本的等权平均远大于折扣值（THR 在 0.04 ~ 0.06 量级），
  因此"是否达标"必须说明统计口径，不能把折扣达标解释为每天都达标。
- **WDD 无法被激活**：该库生态约束在所有已记录状态中恒被满足，
  预算无法制造违规；如果评审要求"五库约束项都非零"，那是数据不支持的要求，
  应记录为约束在该库不生效，而不是人为压低预算。
- 本校准同时写入 `harl/configs/envs_cfgs/cascade_reservoir.yaml`（仓库默认环境配置）与
  `harl/configs/experiments/cascade_budget_calibrated.json`（可直接运行实验配置）。
  历史 `cascade_budget_00001.json`（0.0001）与 `cascade_budget_001.json`（0.01）
  保持原值，用于复现与对照。
